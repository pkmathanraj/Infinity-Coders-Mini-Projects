# Infinity Coders — 3 Mini Projects

Small Streamlit projects for school Computer/Tech Club students.

## Projects

1. `guess_the_number.py` — Grades 6–8
2. `password_strength_checker.py` — Grades 8–10
3. `electricity_bill_calculator.py` — Grades 8–10

## Install

```bat
pip install -r requirements.txt
```

## Run

```bat
streamlit run guess_the_number.py
streamlit run password_strength_checker.py
streamlit run electricity_bill_calculator.py
```

## Student concepts

**Guess the Number:** variables, random numbers, conditions.

**Password Strength Checker:** strings, regular expressions, conditions, scoring. Use dummy passwords only.

**Electricity Bill Calculator:** input, arithmetic, functions, slab-based conditions. Example rates are generic and editable in the app.
